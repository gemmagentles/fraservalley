# Fraser Valley Gaels Football Club

A custom WordPress website for the Fraser Valley Gaels Football Club in Vancouver.

This repository contains the site setup, WordPress theme files, plugins, and supporting configuration for the club's online presence.

## Project structure

- `themes/` — custom WordPress theme and front-end assets
- `plugins/` — site plugins and custom functionality
- `mu-plugins/` — must-use plugins
- `uploads/` — uploaded media and generated site content
- `smush-webp/` — WebP optimization assets
- `index.php` — WordPress entry point

## Local setup

This project is designed to run as a WordPress site in a local environment.

1. Clone the repository into your local WordPress install.
2. Ensure the site is configured to use the project root as the WordPress installation.
3. Install the required WordPress plugins and activate the theme from the admin dashboard.
4. Run the site locally and make updates through the WordPress admin.

## Notes

This project is a WordPress website for a football club, with custom theme work, plugin integrations, and media assets managed in-repo.
